## メジャー 2 の初版問題集の変更

2 では四サイズの迷路を組み直し、初版の一部を外しました。`/levels/legacy` は 1.0 の番号、設定、現在の対応を読みます。現行の問題集から外れても、同じ設定は同じ迷路を作ります。新番号を推測して保存結果を置き換えません。

## メジャー 3 の得点順

3 は 2.3 の設定を保持し、迷路、縦長、巨大、立体を、形の覆い方を含む得点順へ並べ直しました。設定で保存した結果は保たれ、サイズと番号だけのリンクは別の迷路になる場合があります。独自の MazeGeometry には `points` が加わりました。標準の関数を使うか、有効な二次元・三次元の中心と各関数を渡します。

現在の公開メジャーは 3 です。[変更履歴](../../../CHANGELOG.md)と [LEVELS.md](../../LEVELS.md)に詳細があります。今回の案内とコメントの変更は動作、配列、版を保ちます。埋め込みのメソッド、プロパティ、独自設定は [従来の仕様](../../embeds.md)のままです。番号だけの意味を保つなら問題集の版を固定します。
